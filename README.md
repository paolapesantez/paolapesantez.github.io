# 👋 Hi, I'm Paola

This is the source for my personal research site — built with [Quarto](https://quarto.org) and Python, 
because I wanted a homepage that could keep up with the actual challenges of doing research: code, data, 
half-finished notes, and the occasional live chart that updates itself when I re-run it.

🔗 **Live site:** [https://paolapesantez.github.io/](https://paolapesantez.github.io/)

---

## What's here

A lightweight academic website — no CMS, no database, just plain text files that render into a fast static 
site:

- **Research** — what I actually work on, written like I'd explain it over coffee, not like a grant proposal
- **Publications** — pulled straight from a `.bib` file, awesome!
- **Notes** — short write-ups where the code and the explanation live in the same file
- **CV** — the path traveled, kept in sync with the same publication data as everything else

## Why Quarto + Python

I didn't want to choose between "site that looks good" and "site that can actually run an analysis." 
Quarto lets a chart be *real Python output*, computed at build time, instead of a screenshot I forget 
to update. If the data changes, I just re-render — the whole site catches up.
